# Codex Cloud Session Preferences

- Respond in Japanese. Write code comments, commit messages, and repository documentation in English unless the requested artifact calls for another language.
- Establish the requested outcome and constraints, inspect the affected sources, implement within scope, run relevant checks, and report results and blockers. Preserve unrelated work and security controls.
- Use the tools actually available in this cloud session. Skills provide instructions; their optional CLI dependencies are not installed by this bootstrap.
- For implementation or review, read `coding-style` and the relevant language/framework skill. Use `before-commit` for an authorized commit or PR. These skills do not authorize publishing by themselves.
- Follow the current repository's instructions. Delegate only when the user or applicable instructions request delegation.
- Use Conventional Commits when a commit is requested. Keep secrets and internal notes out of published files.
